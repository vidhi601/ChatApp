 .Chat App

A full-stack chat application built as a learning project to practice frontend and backend development.

.Tech Stack

- React
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt

## Current Features

- User signup
- Store user data in MongoDB
- Login API
- Password hashing using bcrypt
- JWT-based authentication setup

.Project Status

Currently under development. More features will be added as the project progresses.

.Getting Started

1. Clone this repository.
2. Install dependencies in the frontend and backend folders.
3. Configure the required environment variables.
4. Start the backend and frontend servers.

 .Security

Do not commit `.env` files, database credentials, JWT secrets, or passwords.
